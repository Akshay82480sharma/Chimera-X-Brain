## 🎯 THE CORE PRODUCT IDEA (do not lose this while refactoring)

Chimera-X has ONE persistent "brain" (conversation history + memory + context) that is completely decoupled from WHICH AI model answers at any given moment.

The system must be able to:
1. Switch between models/providers (Claude, OpenAI, Google Gemini, GLM, local models via Ollama) **mid-conversation** with zero data loss and zero context gaps.
2. Automatically fall back to a different provider when the current one hits a rate limit or quota error — **without the user noticing**, and without losing any conversational context.

**Golden rule:** The model is a disposable "mouth." The brain (DB) is the only source of truth. Nothing about stored context, memory, or history may ever depend on which model generated it.

```
[ build_context(conversation_id) ]   ← BRAIN — 100% model-agnostic
              ↓
[ router.select_provider(...) ]      ← ROUTER — stateless, real-time decision
              ↓
[ litellm.complete(context, provider) ] ← MOUTH — fully disposable
              ↓
[ save_message(conversation_id, response, provider_used) ] ← back to BRAIN
```

If any code you write violates this separation (e.g., context-building logic that checks "if provider == X"), stop and flag it to me before proceeding.
